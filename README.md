# X Bookmarks Exporter

Xのブックマークを取得してMarkdownファイルに出力するChrome拡張機能。

Xの投稿はAiでクローリングできないようになっている。そのためURLを渡しても文章を解析、要約してくれない。

解説、要約させたい投稿が自分の場合ブックマークに溜まっているので、これをダウンロードできるようにすることでAIに読ませられるようにした。

## インストール手順

1. このリポジトリを ZIP でダウンロード or `git clone`
2. Chrome で `chrome://extensions/` を開く
3. 右上の **「デベロッパーモード」** を ON
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. ダウンロードしたフォルダを選択

## 使い方

1. X (<https://x.com>) にログインする
2. **<https://x.com/i/bookmarks>** を開いてページが読み込まれるのを待つ
3. ブラウザのツールバーから **X Bookmarks Exporter** アイコンをクリック
4. 「準備完了」と表示されたら **「Markdown に出力」** を押す
5. `x-bookmarks-YYYY-MM-DD.md` がダウンロードされる

## 出力形式

```markdown
# X Bookmarks - 2026/05/24

> 合計 **123** 件

---

## 1. 表示名 (@screen_name)

- **投稿日時**: 2026/01/15 10:30:00
- **URL**: <https://x.com/screen_name/status/...>

ツイートのテキスト内容

---
```

## 注意事項

- X の内部 GraphQL API を使用しているため、仕様変更で動作しなくなる場合があります
- 使用には X へのログインが必要です
- ブックマーク数が多い場合、取得に時間がかかります（レート制限対策で 500ms 間隔）
- リツイートはエクスポート対象外です（元ツイートのみ出力）
